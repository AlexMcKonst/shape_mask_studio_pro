🎭 Shape Mask Studio Pro

Shape Mask Studio Pro — это мощное веб-приложение для создания сложных видеоколлажей, 
виджеинга (VJing) и композитинга в реальном времени. 
Инструмент позволяет вырезать видео по контуру любых фигур, создавать сложную булеву графику 
и гибко управлять медиа-контентом прямо в браузере без использования сторонних серверов.

Проект идеально подходит для создания видеоарта, VJ-сетов, оформления сторис 
или нестандартных визуальных эффектов с высокой производительностью.

✨ Ключевые возможности

✂️ Продвинутое маскирование и Векторы

Универсальные формы: Поддержка базовых фигур, полигонов (с редактированием точек), произвольного рисования (Freehand) и 
текстовых масок (с возможностью редактирования написанного текста "на лету").

Библиотека векторов (SVG/PNG): Загружайте собственные формы или целые папки. 
Поддерживается Drag & Drop — просто перетащите нужную иконку из библиотеки прямо на холст!

Умные рамки выделения (Bounding Box): Профессиональный контроль масок с помощью 8-точечной рамки 
(цветокодированные квадраты для масштабирования и круги для вращения вокруг геометрического центра фигуры).

🧲 Булевы операции и Контуры

Сложение и Вычитание (+/-): Создавайте сложные формы, комбинируя фигуры или вырезая "дырки" 
(например, отверстия в полигонах). Ошиблись? Любую добавленную часть можно удалить одним кликом (🗑️).

Alpha Contour Tracer: Уникальный алгоритм, который автоматически сканирует прозрачность (альфа-канал) 
пользовательских SVG/PNG и рисует идеальную обводку.

Монолитная обводка (Merged Contours): Для сложных булевых групп программа генерирует единый, 
гладкий внешний контур, игнорируя внутренние пересечения.

Z-Order контура: Три режима наложения обводки на выбор: Outer (снаружи), Inner (внутри, поверх видео) и Center (по границе).

🎥 Управление видео и VJ-инструменты

Синхронизация трансформаций: Видео намертво привязывается к маске при перемещении и вращении, как в профессиональных редакторах.

Инструмент Pan Media: Точное внутреннее позиционирование и масштабирование видео внутри границ маски (без изменения самой формы).

Локальный Play/Pause: Возможность останавливать или запускать видео внутри каждой конкретной маски независимо от остального проекта.

Glitch Mosaic: Встроенный VJ-генератор для мгновенного разрезания экрана на заданное количество хаотичных плиток.

🚀 Производительность и Экспорт

Адаптивная детализация: Кнопка качества (HQ / LQ) динамически снижает нагрузку на процессор 
при отрисовке сложных контуров во время работы (до 4х раз), при этом финальный рендер всегда идет в максимальном качестве.

Умный лимит FPS: Ограничение предпросмотра в 60 FPS для предотвращения перегрузки на мониторах 144Hz+.

Аппаратный экспорт: Запись видео (WebM/MP4) в 30 FPS. Доступны режимы: бесконечный (Manual), 
по таймеру (Custom) или автоматический цикл по длине фонового видео (Background Duration).

Менеджмент проектов: Сохранение/загрузка проектов в формате JSON 
и ведение локальной библиотеки любимых шаблонов (сохраняются во внутреннюю память браузера).

🛠 Технологии

Проект работает полностью на стороне клиента (Client-side), обеспечивая максимальную приватность и скорость:

Vanilla JavaScript (ES6+)

HTML5 Canvas API (Многослойный рендеринг, композитинг и Alpha-трейсинг)

Tailwind CSS (Стилизация современного адаптивного интерфейса на 100dvh)

MediaRecorder API (Аппаратно-ускоренный экспорт видео)

🚀 Как начать использовать

Никакой сборки, Node.js или установки зависимостей не требуется!

Скачайте репозиторий.

Откройте файл index.html в любом современном десктопном или мобильном браузере.

Перетащите видео на холст и начните творить!

Обновление 0.0.2

🚀 Обновление Shape Mask Studio Pro (Changelog)

Сегодняшнее масштабное обновление направлено на повышение точности работы с масками, 
улучшение UX для мобильных и десктопных устройств, а также серьезную оптимизацию производительности.

✨ Новые функции (New Features)

Alpha Contour Tracer & Merged Contours: Полностью переписан алгоритм создания обводок. 
Теперь программа идеально обводит сложные SVG/PNG по альфа-каналу прозрачности и 
создает единый монолитный контур для сложных булевых групп (вместо обводки каждой детали по отдельности).

Настройка Z-order для обводки: Добавлены 3 режима наложения контура: Outer (наружу от границ), 
Inner (внутрь поверх видео) и Center (по центру границы).

Drag & Drop для векторов: Иконки из библиотеки (🌟) теперь можно перетаскивать мышкой прямо на холст.

Локальный Play/Pause: В свойствах маски появилась кнопка для остановки/запуска видео внутри конкретной фигуры,
независимо от глобального плеера.

Редактирование текста: Добавлена кнопка "Edit Text" для быстрого изменения содержимого текстовых масок без их пересоздания.

🎯 Улучшения интерфейса и управления (UI / UX)

Профессиональный Bounding Box (8 точек): Рамка выделения теперь имеет цветные маркеры: 
угловые квадраты (масштабирование) и центральные изумрудные круги (вращение).

Улучшенные хит-боксы: Зона захвата контроллеров увеличена для удобства, при этом малые маски 
теперь легко перемещаются (центр не перекрывается точками трансформации).

Синхронизация видео и маски: Теперь при перемещении или вращении маски видео намертво привязано к ней и 
двигается как единое целое (сдвиг видео внутри контура доступен через отдельный инструмент Pan Media).

Удаление дочерних масок: В режиме "Edit Shape" добавлена кнопка (🗑️) для удаления неудачных вырезов из булевой группы.

Адаптация под мобильные: Интерфейс переведен на 100dvh, что предотвращает скрытие панели инструментов 
за адресной строкой в Safari/Chrome на iOS и Android.

Информативные уведомления: Добавлено всплывающее окно при сохранении шаблонов масок с объяснением, что они хранятся в localStorage браузера.

🛠 Исправления багов (Bug Fixes)

Инструмент Полигон (Polygon):

Исправлен центр вращения (Pivot) — теперь полигоны вращаются и масштабируются от своего геометрического центра, а не от первой точки.

Уменьшена зона прилипания (с 25 до 12px), что позволяет ставить точки близко друг к другу без "глюков".

Устранен баг с исчезновением или смещением недорисованного полигона при выходе из режима редактирования.

Логика Edit Mask:

Режим вырезания (- Sub) теперь включается по умолчанию при входе в редактирование.

Исправлено зависание интерфейса (невозможность выйти в глобальный режим перемещения) при нажатии кнопки 'Done'.

Отображение рамок: Рамка выделения (Bounding Box) теперь точно обхватывает сложные полигоны и текстовые маски, учитывая матрицу смещения холста.

🚀 Оптимизация (Performance)

Лимит FPS: Установлено жесткое ограничение в 60 FPS для предпросмотра, что предотвращает 2.5-кратный перегруз процессора на мониторах 144Hz+.

Адаптивная детализация: Тяжелый алгоритм отрисовки сложных обводок теперь привязан к кнопке качества. 
В режимах LQ детализация снижается в 2-4 раза для спасения CPU, не влияя на качество финального экспорта.

Разблокировка GPU: Сняты флаги принудительного чтения пикселей (willReadFrequently), что переносит часть нагрузки по композитингу на видеокарту.
